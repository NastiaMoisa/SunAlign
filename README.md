# SunAlign

Підказка орієнтації панелі.

Мойса Анастасія Святославівна, ІО-36, № у списку не надано.

Компоненти: MPU6050 I2C, два LDR ADC, кнопка GPIO.

Середовище: Ubuntu 24.04, Docker, STM32 HAL, Wokwi. Платформа Nucleo-C031C6.

Зарезервовано тему. Скопійовано початковий шаблон UART/LED без Git-історії, без драйверів сенсорів. ЛР1 ще потребує PRD, дослідження компонентів, власних збірок, запусків, скриншотів та звіту. ЛР2 додає драйвери, тести й одночасне опитування.

`make build` збирає прошивку. Схема `diagram.json`, налаштування Wokwi `wokwi.toml`.

Git identity та origin для цього проєкту ще не налаштовані. Комітів немає.
