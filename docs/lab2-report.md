# ЛР2. Інтеграція сенсорної підсистеми SunAlign

Мойса Анастасія Святославівна, ІО-36.

Мета: одночасно інтегрувати MPU6050, два LDR та кнопку на NUCLEO-C031C6, перевірити сигнали й відокремити прикладну логіку від STM32 HAL. Середовище: Ubuntu 24.04, Docker, STM32 HAL, Wokwi. Остаточний [PDF](lab_2/report.pdf) містить титул, таблиці, схему, реальні скріншоти й висновки.

## Результати

| Перевірка | Фактичний результат |
|---|---|
| Docker build | ARM GCC 13.2, власний код -Wall -Wextra -Werror, Cortex-M0+ |
| WHO_AM_I | 0x68 при адресі 0x68 |
| Статичний вектор | 00 00 00 00 40 00, 0/0/1000 mg у UART та на SDA |
| LDR | 1123/1123 при 400/400 lux у моделі |
| Контраст | 156/3411 дає LEFT; 3411/156 дає RIGHT |
| ZERO і нахил | Натискання дає zero=1; accelX=0.5, accelZ=0.85 дають близько 30.49°, LOWER |
| Темрява | 3938/3938 при 1/1 lux, DARK |
| Адресний NACK | 0x69 Write, NACK, STOP; ERROR без зупинки ADC/UART |
| Відновлення | Повторна ініціалізація через 1 с; imu=1 у логах t=2001 мс |
| Покриття | 94/95 рядків, 108/113 гілок, 11/11 функцій portable шарів |

Схема й аргументація містяться в [pinout.md](pinout.md); шари, component diagram і правила залежностей у [architecture.md](architecture.md). Оригінали VCD, SR, налаштування PulseView та [декодований аналіз](captures/analysis.md) містять нормальний ID, шість байтів акселерометра, UART, ADC-маркер і навмисну аномалію. Короткі фрагменти отримано з повних записів із збереженням походження й SHA-256.

## Тестування

Вісім host-груп перевіряють порядок ID/wake/config/range/sample, NACK/timeout/неочікуваний ID, pending/busy, повторну спробу, wraparound, знакові перетворення, реальні захоплені байти, IIR, напрямки й темряву, кнопку та одночасні світло/нахил/натискання. Пороги 90% рядків і 75% гілок задані в tests/Makefile. Вони не підмінюють перевірку HAL/IRQ у симуляторі. Неохоплена захисна гілка драйвера вимагає пошкодження внутрішнього enum стану. HAL, Cortex, периферія та фізичні електричні властивості до host coverage не входять.

## Фактичні проблеми

1. Host GCC не знаходив stdint.h, бо Docker мав gcc без libc6-dev при --no-install-recommends. Додано пакет заголовків.
2. Mem_Read_IT з HAL 1.0.1 зависав у фазі TC. Capture і вихідний HAL дали причину; адаптер перейшов на IRQ-керовані Master Transmit/Receive із STOP між фазами. Busy тепер має watchdog.
3. Початкова -Og збірка наближалася до межі Flash 32 КБ. -Os зменшив остаточний образ до 29156 байтів Flash.
4. Поріг DARK=160 не спрацьовував при 1 lux: реальний ADC моделі дав 3938/3938. Поріг суми B змінено на 500, додано регресійний тест.
5. Початкова ініціалізація PC13 EXTI суперечила новому pinout з PB0. Прибрано невикористаний init/EXTI module, збережені .ioc і diagram.json перевіряються автоматично.

Реалізація: `fbdf596`; виправлення: `774478e`. Git-ідентифікатори посилаються на локальну історію. Перевірки та записи мають фактичну дату 16.10.2026.

Форма B охоплює I²C, ADC, GPIO й UART. Камера, SCCB, SPI-пам'ять та PWM-привід не належать до продукту. Wokwi не підтверджує живлення, rise time, шум ADC або точність фізичного LDR. Віддалений CI і фізична плата не перевірялися.
