# SunAlign: поточні результати ЛР3

Джерела `src-af2d5aa374d1`; досліджений ELF SHA-256 `9791f5375be0fea0e576c3d3c857ba3c16355593547e42675980834e502f8471`. Дані — Wokwi, не фізична плата. Повна готовність не заявляється. Місцеві первинні файли збережені поза репозиторієм у `Lab03/Work/clock-flash-revision`: абсолютне розташування й інструкція в `Lab03/Work/GUIDE.md`. Не видавайте попередні досліди іншого ELF за результати цієї збірки.

- S1: 30,498 с MCU за UART, 305 інтервалів ADC, понад 30 тис. інтервалів panel; незалежний VCD. Окреме підтвердження положень повзунків не збережено.
- S2: один безперервний інтервал 3 600 000 мс MCU після GO, 7201 декодований PANEL у VCD, максимальний інтервал 501 мс. ADC 38 735 інтервалів: MCU 96000/99999/104000 мкс; VCD 96633,575/99997,896/103318,775 мкс. S2 TX lost=0, panel missed=773, stack watermark=584 B, heap=0. Статистика накопичувальна від старту.
- S3: 150498 мс MCU, 60 пар D4/D7 з D6 HIGH, max 31,979425 мс; у UART розпізнано 59 ZERO, наприкінці TX lost=301 B, panel missed=9102 та deadline misses=1403. Причину конкретної відсутньої UART-події не встановлено. D6 є об'єднанням експорту і Flash.
- `n` на 6500 мс викликала ERROR у PANEL 7000 і 7500 мс, до 8000 мс стан відновився; `c` на 15500 мс не була причиною цього відновлення. Це модельна відмова адреси; сценарій від’єднання датчика або утримання SDA на поточному ELF окремо не виконано, як і старт із підключеним, але не готовим сенсором.
- UART навантаження з цільовими 2/5/10/20/40 запитами/с: фактична інтенсивність надсилання за host-часом 1,92/4,44/7,97/16,23/32,42 запиту/с. Останній повний RES біля PANEL 60000 мс показав нуль втрат RX/TX, але після нього повного фінального RES немає; першу частоту втрат не встановлено. VCD фіксує TX, але не RX.
- Окремий короткий boundary-drain: 8 с host на кожному рівні і 4 с без `d` до статистики. Фактичні швидкості 1,967 / 4,719 / 9,493 / 16,004 / 24,054 запитів/с; прирости TX lost відповідно 0 / 0 / 0 / 24003 / 74847 байтів, RX lost/errors залишилися нульовими. Перші спостережені втрати — після рівня 16,004 та паузи в цьому сценарії, точний поріг між рівнями невідомий. Усі шість рядків RES незалежно збіглися з UART TX з VCD, framing errors=0; VCD не містить RX. Новий `d` може перезапустити експорт.
- Три команди `s` після ZERO повернули `SAVE ... 0`; успішний запис/читання і power-cut не підтверджені.

SysTick має роздільність 1 мс, CPU load і субмілісекундний WCET недоступні. Статистика не гарантує поведінки фізичного MCU чи всіх можливих навантажень. Для детальних входів, UTC команд, hashes і сирих журналів див. місцевий GUIDE та записи сценаріїв.

Повторна незалежна Docker-збірка коміту 9f21692 в окремому каталозі відтворила ELF/HEX/BIN побайтно; host-тести пройшли. Фактичні ресурси linker: Flash 23180 з 28672 B, RAM з резервами 6104 з 12288 B. Окремий build-current із робочих джерел дав ті самі hashes.
