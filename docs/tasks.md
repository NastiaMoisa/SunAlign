# Задачі ЛР3

Платформа Nucleo-C031C6, Cortex-M0+, HSI/APB 48 МГц. ОС немає.

| Задача | FR | Період / подія | Критерій |
|---|---|---|---|
| board | 03,10,11 | кожна ітерація, ADC 100 мс | watchdog ADC 10 мс, I2C 20 мс |
| MPU state machine | 04,10,11,12 | кожна ітерація, absolute release 100 мс | retry 1000 мс |
| panel | 05-10 | 1 мс, без catch-up | стабільне натискання 30 мс; ціль реакції 50 мс |
| heartbeat | 02 | 500 мс, absolute cadence | ціль запізнення до 5 мс |
| log/history | 01,09 | 500 мс | 32 останні точки у RAM, deadline 20 мс |
| command | 12-14 | RX IRQ, 64 slots, один байт за цикл | ціль RX callback-to-dispatch 10 мс |
| save | 13 | s після ZERO | реальний erase+3 doubleword, перевірка CRC |
| export | 14 | d, одна точка не частіше разу на 1 мс | snapshot 32 точки, PA6 до спорожнення TX |
| statistics | 14 | t | 19 рядків по одному за цикл |
| restart | 01,13 | r, окремий діагностичний дослід | NVIC_SystemReset, не power cycle |

Числові цілі ЛР3 є критеріями перевірки, а не підтвердженими гарантіями.
Тривала передача UART розбита на короткі кроки. Нова d починає snapshot заново,
тому часті d можуть не дати експорту завершитися. Переповнення TX відкидає
окремі нові байти, тому рядки можуть бути неповними. Виклик Flash не
витісняється foreground-задачами. Успішний erase у моделі поки не підтверджено.
